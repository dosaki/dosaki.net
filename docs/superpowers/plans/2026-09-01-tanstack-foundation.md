# TanStack Router Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace dosaki.net's Create React App toolchain with Vite + React 19 + TypeScript + TanStack Router, extracting all site content into typed modules in the repo, with deliberately minimal styling ahead of a separate design overhaul.

**Architecture:** A file-based-routing SPA. Four routes generated from `src/routes/`. All content — prose, projects, talks, language stats — lives in typed modules under `src/content/` and is resolved at build time, so the app makes no runtime data requests. Output goes to `build/` so the existing Terraform/CloudFront deployment is untouched.

**Tech Stack:** Vite 8.2.2, React 19.2.8, TypeScript 7.0.2, @tanstack/react-router 1.170.32, @tanstack/router-plugin 1.168.35, Vitest 4.1.11, echarts 6.1.0, echarts-for-react 3.0.6

**Spec:** [`docs/superpowers/specs/2026-09-01-tanstack-foundation-design.md`](../specs/2026-09-01-tanstack-foundation-design.md)
**Inventory:** [`docs/superpowers/specs/2026-09-01-content-and-feature-inventory.md`](../specs/2026-09-01-content-and-feature-inventory.md)

## Global Constraints

- **Branch:** all work happens on `rebuild/tanstack-foundation`. Never commit to `master` — pushing there triggers a production deploy.
- **Build output directory MUST be `build/`** (not Vite's default `dist/`). Terraform reads `../build`; changing it breaks the deploy.
- **Node ≥ 22.** Vite 8 requires ≥20.19; CI pins 22.
- **No `NODE_OPTIONS=--openssl-legacy-provider` anywhere.** It existed only for webpack 4.
- **Removed dependencies — do not reintroduce:** `react-scripts`, `react-router-dom`, `axios`, `uuid`, `web-vitals`, `@fortawesome/*`.
- **No new runtime dependencies** beyond those in the Tech Stack line. Use plain `fetch`, plain functions for validation (no zod).
- **Minimal styling only:** one global stylesheet — reset, readable typography, max-width column, existing palette on text/background/links. No layout systems, cards, animations, or responsive work. The design overhaul replaces this.
- **Palette (from the old CSS, reuse verbatim):** `#e1aa7d` primary accent, `#e28941` darker accent, `#2e2836` dark background, `#454247` / `#535055` mid greys, `#fffdfb` / `#fff2e7` off-whites, `#b5777e` muted rose.
- **`list_key` rule:** never use a generated UUID as a React key. Keys come from stable data fields.
- **Content is build-time.** No component may fetch at runtime.

## Prerequisites

- **Remove the `@fortawesome` scope override from `~/.npmrc`.** Two lines redirect
  that scope to `npm.fontawesome.com` with an expired token, so any install touching
  it fails with `E401`. This plan drops those packages, so nothing here depends on it
  — but leave the override in place and the next person to add a `@fortawesome`
  dependency hits the same wall. **This edits the developer's machine, not the repo.**
- **TypeScript 7 fallback.** TS 7 is the young native rewrite. If a dependency's types
  misbehave in a way that is not the plan's fault, drop to the latest TypeScript 5.x,
  say so explicitly, and carry on. Do not weaken `strict` to work around it.

- [ ] **Step 4: Write `src/content/ordering.ts`**

```typescript
import type { Project, ProjectStatus, Talk } from './types'

const STATUS_BAND: Record<ProjectStatus, number> = {
  active: 0,
  done: 1,
  inactive: 2,
}

export function orderProjects(projects: Project[]): Project[] {
  return [...projects].sort((a, b) => {
    const band = STATUS_BAND[a.status] - STATUS_BAND[b.status]
    if (band !== 0) return band
    return a.type.localeCompare(b.type)
  })
}

export function orderTalks(talks: Talk[]): Talk[] {
  return [...talks].sort((a, b) => b.date - a.date)
}
```

```tsx
import { ICON_PATHS, type IconName } from './paths.generated'

interface IconProps {
  name: IconName

  title?: string
  className?: string
}

export function Icon({ name, title, className }: IconProps) {

      className={className}
      viewBox={`0 0 ${w} ${h}`}

      height="1em"

      role={title ? 'img' : undefined}
      aria-hidden={title ? undefined : true}
    >
      {title ? <title>{title}</title> : null}
      <path d={d} />
    </svg>
  )
}
```

- [ ] **Step 2: Write `scripts/generate-languages.mjs`**

Plain `.mjs` so Node runs it with no extra tooling dependency.

```javascript
import { readFileSync, writeFileSync } from 'node:fs'
import { fileURLToPath } from 'node:url'
import { dirname, resolve } from 'node:path'

const here = dirname(fileURLToPath(import.meta.url))
const seedPath = resolve(here, '../src/content/languages.seed.json')
const outPath = resolve(here, '../src/content/languages.generated.ts')

const USER = 'dosaki'
const CURRENT_YEAR = new Date().getFullYear()

/** GitHub reports Vue separately; the site counts it as JavaScript. */
const ALIASES = { vue: 'javascript' }

function loadSeed() {
  const seed = JSON.parse(readFileSync(seedPath, 'utf8'))
  for (const stat of Object.values(seed)) {
    if (stat.startYear !== null && stat.endYear === null) {
      stat.endYear = CURRENT_YEAR
    }
  }
  return seed
}

async function fetchJson(url) {
  const res = await fetch(url, {
    headers: { Accept: 'application/vnd.github+json', 'User-Agent': 'dosaki.net-build' },
  })
  if (!res.ok) throw new Error(`${res.status} ${res.statusText} for ${url}`)
  return res.json()
}

async function augment(languages) {
  const repos = await fetchJson(`https://api.github.com/users/${USER}/repos?per_page=100`)
  const owned = repos.filter((repo) => !repo.fork)

  for (const repo of owned) {
    const names = Object.keys(await fetchJson(repo.languages_url))
    const year = new Date(repo.created_at).getFullYear()

    for (const raw of names) {
      const key = ALIASES[raw.toLowerCase()] ?? raw.toLowerCase()
      const stat = languages[key]
      if (!stat) continue

      if (!stat.projects.includes(repo.name)) stat.projects.push(repo.name)
      stat.startYear = Math.min(year, stat.startYear ?? 9999)
      stat.endYear = Math.max(year, stat.endYear ?? 0)
    }
  }
  return owned.length
}

const languages = loadSeed()

try {
  const count = await augment(languages)
  console.log(`generate-languages: merged ${count} GitHub repositories`)
} catch (error) {
  console.warn(`generate-languages: falling back to seed only — ${error.message}`)
}

writeFileSync(
  outPath,
  `// GENERATED by scripts/generate-languages.mjs — do not edit by hand.\n` +
    `// Regenerate with: npm run generate:languages\n\n` +
    `import type { LanguageMap } from './types'\n\n` +
    `export const languages: LanguageMap = ${JSON.stringify(languages, null, 2)}\n`,
)
console.log(`generate-languages: wrote ${outPath}`)
```

```tsx
import ReactEChartsCore from 'echarts-for-react/lib/core'
import * as echarts from 'echarts/core'
import { PieChart } from 'echarts/charts'
import { LegendComponent, TitleComponent, TooltipComponent } from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
import type { LanguageMap } from '../content/types'

echarts.use([TooltipComponent, LegendComponent, TitleComponent, PieChart, CanvasRenderer])

/** Positional, aligned with the ten seed languages. */
const COLOURS = [
  '#f7e018', '#4298b8', '#ea2d2e', '#36008e', '#00acd7',
  '#00007c', '#5c41e2', '#888888', '#f7c93e', '#293036',
]

export type ChartMode = 'projects' | 'years'

interface LanguageChartProps {
  languages: LanguageMap
  by: ChartMode
}

export function LanguageChart({ languages, by }: LanguageChartProps) {
  const data = Object.entries(languages).map(([name, stat]) => ({
    name,
    value:
      by === 'projects'
        ? stat.projects.length
        : (stat.endYear ?? 0) - (stat.startYear ?? 0) || 1,
  }))

  const option = {
    title: {
      text: by === 'projects' ? 'Languages used (by project)' : 'Languages used (by years used)',
      left: 'center',
      textStyle: { color: '#ccc' },
    },
    tooltip: {
      trigger: 'item',
      formatter: (params: { name: string; value: number }) =>
        `${params.name}: ${params.value} ${by}`,
    },
    series: [
      {
        type: 'pie',
        radius: ['40%', '80%'],
        label: { show: true, fontWeight: 'bold' },
        data,
        color: COLOURS,
      },
    ],
  }

  return (
    <ReactEChartsCore
      echarts={echarts}
      option={option}
      style={{ height: 400 }}
      notMerge
    />
  )
}
```

- [ ] **Step 4: Write `src/routes/about.tsx`**

`validateSearch` is a plain function — no schema library needed.

```tsx
import { Link, createFileRoute } from '@tanstack/react-router'
import { Icon } from '../icons/Icon'
import { LanguageChart, type ChartMode } from '../components/LanguageChart'
import { languages } from '../content/languages.generated'
import { site } from '../content/site'

interface AboutSearch {
  by: ChartMode
}

export const Route = createFileRoute('/about')({
  validateSearch: (search: Record<string, unknown>): AboutSearch => ({
    by: search.by === 'years' ? 'years' : 'projects',
  }),
  component: About,
})

function About() {
  const { by } = Route.useSearch()
  const { heading, photo, aside, social, paragraphs, languagesIntro } = site.about
  const other: ChartMode = by === 'projects' ? 'years' : 'projects'

  return (
    <section>
      <h1>{heading}</h1>

      <p>
        {social.map((link) => (
          <a key={link.href} href={link.href} aria-label={link.label}>
            <Icon name={link.icon} title={link.label} />
          </a>
        ))}
      </p>

      {paragraphs.map((parts, index) => (
        <p key={index}>
          {parts.map((part, partIndex) =>
            part.href ? (
              <a key={partIndex} href={part.href}>{part.text}</a>
            ) : (
              <span key={partIndex}>{part.text}</span>
            ),
          )}
        </p>
      ))}

      <img src={photo.src} alt={photo.alt} width={200} />
      <p>{aside}</p>

      <p data-testid="chart-mode">{by}</p>
      <LanguageChart languages={languages} by={by} />

      <p>
        {languagesIntro.prefix}
        {by === 'projects' ? (
          languagesIntro.byProjects
        ) : (
          <Link from={Route.fullPath} search={{ by: 'projects' }}>
            {languagesIntro.byProjects}
          </Link>
        )}
        {languagesIntro.middle}
        {by === 'years' ? (
          languagesIntro.byYears
        ) : (
          <Link from={Route.fullPath} search={{ by: 'years' }}>
            {languagesIntro.byYears}
          </Link>
        )}
        {languagesIntro.suffix}
      </p>
      <p>
        <Link from={Route.fullPath} search={{ by: other }}>
          {`Show by ${other}`}
        </Link>
      </p>
    </section>
  )
}
```
